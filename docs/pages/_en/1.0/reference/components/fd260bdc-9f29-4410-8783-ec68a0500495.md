---
title: Add Floor (Sloped)
toc: false
---

This component works like *Add Floor* and takes the same first five inputs, so it can replace it on a canvas without rewiring. It adds two inputs that give the floor a slope, the way a slope arrow is drawn in Revit sketch mode:

- **Slope Arrow** is a line in plan. It starts where the floor is at its height and points uphill. Its height is ignored; the arrow is placed on the boundary plane.
- **Slope** is the angle along the arrow. Like every angle input it expects radians; right-click the input and pick *Degrees* to type degrees.

The floor keeps its element when the slope, arrow, type, level, structural flag or boundary position change. Every floor is created with a slope arrow, one of slope 0 when it is flat, because the Revit API can not add a slope arrow to an existing floor. That is what lets a flat floor be sloped later without being replaced.

Requires Revit 2022 or above.
